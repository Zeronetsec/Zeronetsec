# Zeronetsec
Zeronetsec is a my GitHub README and a simple tool contained within it.

## Features
- Read formatted and raw project documentation directly inside your terminal.
- Fetch GitHub profile details directly.
- Lightweight and fast execution on Linux systems.
- Navigate easily using simple and intuitive command-line options.
- And more features.

## Installation
Quick install:
```bash
git clone https://github.com/Zeronetsec/Zeronetsec
bash Zeronetsec/install.sh
```
For more detailed installation and uninstallation instructions, see [.docs/install_and_uninstall.md](.docs/install_and_uninstall.md).

## Usage Example
```bash
zeronetsec --readme
zeronetsec --raw-readme
zeronetsec --info
zeronetsec --version
zeronetsec --help
```
And more commands.
